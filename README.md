# CarFeed

A deployed automotive culture news feed built from a scraping, archiving, translation, and static-site publishing pipeline.

CarFeed collects articles from multiple public automotive media sources, normalizes them into local JSON data, deduplicates and archives them, and publishes a static web preview for browsing, search, and category filtering.

## What It Demonstrates

- End-to-end path from data pipeline to deployed content product
- Multi-source web scraping with RSS and HTML fallbacks
- Local JSON data modeling, deduplication, and archiving
- Incremental translation workflow
- Static site generation and deployment
- A lightweight content product prototype built from public information sources

## Current Features

- Collect articles from multiple automotive media sources
- Normalize article metadata into JSON
- Archive previously seen items and avoid duplicates
- Categorize content into automotive-related groups
- Generate a static preview site
- Support browsing, search, and category filtering
- Maintain translation and automation status files for repeatable runs

## Tech Stack

- Node.js
- Web scraping
- RSS parsing
- JSON data pipeline
- Translation workflow
- Static site generation
- Deployment
